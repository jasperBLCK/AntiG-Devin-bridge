# Map

- `app.py`: settings, task validation, SQLite, submission, polling and handoff.
- `providers.py`: AntiG text and media clients, Devin API v3, upstream error handling.
- `repository.py`: GitHub tree and pinned, bounded source-file reads.
- `static/`: task form, history, result rendering, workbench styling.
- `tests/`: mocked workflows and demo behavior.

# Product

An operator submits one request. Grok explains the assignment and either answers, asks for clarification, delegates repository work to Devin, or proposes image/video generation. A task can use Grok for planning and report review and Devin for implementation and tests without a manual handoff.

The submitted request defines the goal and deliverable. Grok suggests implementation steps, and selected skills supply methods, not new requirements. If a material change is needed, the agent should ask rather than silently substitute a new task.

The operator can share selected files from a GitHub revision, set the Devin ACU cap and allow a draft PR. The panel shows who is working, session messages, and verified PR branches and paths. Demo uses no keys. Shared hosting, multiple writers per task, automatic merges, and whole-repository ingestion by Grok are out of scope.

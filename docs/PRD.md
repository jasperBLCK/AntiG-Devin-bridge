# Product

An operator can turn a development request into a Grok plan and optionally send that plan to Devin to work on a repository. The panel also supports direct Devin tasks and separate text-to-image and text-to-video modes.

The operator can give Grok selected files from a GitHub revision, reviews the plan, confirms the Devin launch and sets a spend cap. The panel tracks status and links to the session or PR. The demo is usable with no account keys. Shared hosting, autonomous routing, model-to-model loops, whole-repository ingestion by Grok, image editing and video extension are out of scope.

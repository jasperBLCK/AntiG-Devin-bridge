# Product

An operator can turn a development request into a Grok plan and optionally send that plan to Devin to work on a repository. The panel also supports direct Devin tasks and separate text-to-image and text-to-video modes.

The operator reviews the plan and confirms the Devin launch, sets a spend cap, and can track status and open the session or PR. The demo is usable with no account keys. The first version is single-user; shared hosting, autonomous routing, model-to-model loops, repository ingestion by Grok, image editing, and video extension are out of scope.

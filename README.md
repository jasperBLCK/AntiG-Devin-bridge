# Мост · AntiG × Devin

Веб-панель для совместной разработки. Опиши задачу: Grok 4.7 через AntiG сам ответит или поручит Devin изучить репозиторий, выполнить правки и запустить проверки. Панель покажет исполнителя, ход работы и итог.

## Демо на Windows

Нужен Python 3.12+. В PowerShell из папки проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:BRIDGE_MODE = 'demo'
.\.venv\Scripts\python.exe -m uvicorn app:app
```

Открой `http://127.0.0.1:8000`. В демо ключи не нужны, внешних запросов нет. На Linux создай окружение через `python3 -m venv .venv`, используй `.venv/bin/python` и выставь `export BRIDGE_MODE=demo`.

## Реальные задачи

Останови демо. Задай переменные в окружении процесса, а не в коде, браузере или истории команд:

| Переменная | Что указать |
|---|---|
| `ANTIG_API_KEY` | Ключ AntiG для Grok и Imagine |
| `DEVIN_API_KEY` | [PAT или ключ сервисного пользователя](https://docs.devin.ai/api-reference/overview) с доступом к сессиям организации |
| `DEVIN_ORG_ID` | Идентификатор организации Devin с префиксом `org-` |
| `GITHUB_READ_TOKEN` | Запасной вариант без GitHub App: fine-grained PAT с **Contents: Read**, **Pull requests: Read** |
| `GITHUB_WRITE_TOKEN` | Запасной вариант без GitHub App: fine-grained PAT с **Contents: Read and write** |
| `BRIDGE_GITHUB_WRITE_REPOS` | Репозитории для записи через PAT, через запятую. Запись требует `BRIDGE_ADMIN_KEY`. |
| `BRIDGE_MEDIA_HOSTS` | Дополнительные доверенные хосты выдачи Grok Imagine через запятую (без URL и wildcard). |

**Рабочая область.** Открой `/workspace`, укажи репозиторий и ветку. Загрузка снимка и правки не вызывают агентов. Черновики живут в этой вкладке; «Изменения» (Ctrl/⌘+S) показывает сравнение. Публикация создаёт один коммит в новой ветке `bridge/…` от показанного SHA. Базовая ветка не меняется. Правки существующих UTF-8 файлов поддерживаются; создание файлов, произвольный терминал и merge не входят в сценарий. Настройки записи IDE не дают Devin права: для его push и черновика PR включи соответствующее разрешение в задаче, а в Devin подключи репозиторий с правом записи.

### Вход через GitHub

1. [Зарегистрируй GitHub App](https://github.com/settings/apps/new). **Homepage URL** — адрес «Моста» (HTTPS, без пути); **Callback URL** — тот же адрес с `/api/github/callback`; **Setup URL** — с `/api/github/setup`. Отключи **Request user authorization (OAuth) during installation**: «Мост» сам начинает вход с PKCE. Отключи **Webhook → Active**. Для локального запуска можно использовать `http://127.0.0.1:8000`.
2. В **Repository permissions** задай **Contents: Read and write** для чтения и публикации веток, **Pull requests: Read-only** для просмотра PR. GitHub автоматически добавит **Metadata: Read-only**. Не нужны ключ GitHub App, права на Actions, секреты или администрирование.
3. На сервере задай `BRIDGE_ADMIN_KEY`, `BRIDGE_GITHUB_APP_SLUG` (часть URL после `/apps/`), `BRIDGE_GITHUB_CLIENT_ID`, `BRIDGE_GITHUB_CLIENT_SECRET` и `BRIDGE_PUBLIC_ORIGIN` (тот же адрес). Client Secret сгенерируй в настройках GitHub App, храни только на сервере. Используй один процесс и этот же адрес в браузере. Не записывай query-строки OAuth callback в логи прокси.
4. Открой «Мост» → **Подключить GitHub** → подтверди вход на github.com. Нажми **Выбрать репозитории на GitHub**, установи App на выбранные репозитории и вернись в IDE. Для уже установленного App список подгрузится сразу. Для организационного репозитория может понадобиться одобрение владельца организации.

Когда GitHub App включён, серверные PAT не используются для доступа к репозиториям. Подключение хранится в памяти процесса до перезапуска или истечения токена (не дольше 8 часов); затем войди снова. Отключение в «Мосте» удаляет локальное подключение; доступ GitHub можно отозвать в его настройках. Это не заменяет отдельную интеграцию GitHub в Devin. В демо OAuth выключен.

**Проект с фото и видео.** В одном запросе укажи, какие медиа нужно сгенерировать для проекта. «Мост» покажет предложенные запросы под задачей. После подтверждения Grok Imagine создаёт файлы, и «Мост» прикрепляет их к одной сессии Devin через API вложений. При сбое запуска или передачи не повторяет платный запрос автоматически. Демо ничего не генерирует и не отправляет наружу. Используй только доверенные хосты загрузки; поддерживаются JPEG, PNG, WebP и MP4 до 20 МиБ на файл.

В PowerShell можно ввести ключи не показывая их на экране:

```powershell
Remove-Item Env:BRIDGE_MODE -ErrorAction SilentlyContinue
$env:ANTIG_API_KEY = ([pscredential]::new('antig', (Read-Host 'Ключ AntiG' -AsSecureString))).GetNetworkCredential().Password
$env:DEVIN_API_KEY = ([pscredential]::new('devin', (Read-Host 'Ключ Devin' -AsSecureString))).GetNetworkCredential().Password
$env:DEVIN_ORG_ID = Read-Host 'ID организации Devin'
.\.venv\Scripts\python.exe -m uvicorn app:app
```

Не публикуй live-панель без контроля доступа: приложение однопользовательское и использует ключи владельца. По умолчанию слушает только localhost. Веб-превью можно открыть с демо-данными.

## Работа

1. **Опиши задачу.** Укажи GitHub-репозиторий для работы с кодом. Чтобы Grok тоже увидел исходники, выбери до шести файлов, проверь текст и разреши отправку в AntiG. Не передавай секреты или закрытые данные.
2. **Запусти.** Grok выберет маршрут: ответить, уточнить, поручить Devin чтение или реализацию, либо предложить генерацию медиа. Для Devin укажи лимит ACU. У его организации должен быть собственный доступ к целевому репозиторию. По умолчанию правки остаются в сессии; разрешение на черновик PR задаётся отдельно. Ограничения передаются в поручении агенту; для принудительного запрета записи используй права GitHub и политики Devin.
3. **Следи за ходом.** Панель обновляет статусы и сообщения без открытой вкладки. Когда есть PR, его ветку можно открыть в редакторе с подключённым GitHub. При подключении через серверный PAT панель также обновляет список файлов PR в фоне. Точные команды и незакоммиченные правки смотри в сессии Devin.
4. **Проверь итог.** Если включён разбор отчёта, Grok получает исходный запрос и короткий структурированный отчёт Devin, но не его чат и не diff. Это проверка отчёта, а не независимый запуск тестов. Генерация изображения или видео требует отдельного подтверждения.

**Редактор сессии.** В задаче с репозиторием нажми «Открыть редактор». Слева — поиск и дерево файлов, в центре — вкладки, номера строк и подсветка, внизу — журнал. Переключайся между базой задачи и веткой PR, если она есть. Код читается из снимка GitHub, а не из VM Devin; сохранять файлы из редактора нельзя. Просмотр доступен для UTF-8-файлов до 128 КиБ. Из этой страницы код не отправляется агентам.

**Кабинет.** «Обзор» показывает сводку последних задач, расход и лимиты. Там учитываются только токены, которые AntiG вернул для текстовых ответов, и последний измеренный расход ACU каждой сессии Devin. Это не общий баланс аккаунтов; старые задачи без замера и медиа не входят в расход. «Новая задача» открывает форму, а в «Сессиях» находятся история, фильтры и результаты.

**Скиллы.** Открой «Скиллы» в редакторе или на главной. Витрина объединяет тематические подборки Skills.sh, а вкладка «Дизайн» добавляет девять направлений и понимает типовые русские запросы. Поиск не ограничен карточками витрины. All Time, Trending и Hot показывают доступную часть публичных рейтингов. Звёзды и отзывы собирает «Мост». Любую карточку можно сохранить в браузере; для агентов можно установить проверенные текстовые наборы из «Топ Grok + Devin» или «Готовые для агентов». Чужие скрипты не запускаются. В демо внешний каталог отключён по умолчанию; `BRIDGE_PUBLIC_SKILLS=1` включает только публичный каталог.

Реальные вызовы расходуют лимиты провайдеров. После тайм-аута проверь внешний сервис перед повторным запуском. История лежит в локальной SQLite; `BRIDGE_DB` задаёт путь. Запускай один процесс приложения на файл базы. Старая история сохраняется, но новые задачи отправляются только через единую форму.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m mypy app.py orchestration.py providers.py repository.py workspace.py skills_market.py
```

Тесты не вызывают реальные API. [Документация для контрибьюторов](docs/INDEX.md).
